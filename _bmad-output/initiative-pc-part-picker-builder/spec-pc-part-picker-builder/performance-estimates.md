# Performance estimates (v1)

Implements FR-17–FR-18.

Estimates are **directional**, not benchmark substitutes. Architecture documents data sources (e.g., synthetic index from published benchmarks + declared resolution/settings). UI must disclose estimates are directional.

**Shown when:** Build Compatible or Warning, declared workloads and display present (or labeled unknown-display reduced-confidence mode per FR-3).

**Hidden/blocked when:** Compatibility **Invalid**—user message ties estimate to resolving compatibility.

**Tiers (per declared game/app):** e.g., below target / meets target / exceeds target at declared display settings.

**Updates when:** GPU, CPU, RAM, or display context changes.
